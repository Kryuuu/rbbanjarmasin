Kelola konten situs dalam satu tempat

Buat, perbarui, dan publikasikan berita, statistik pembinaan, testimoni UMKM, serta mitra kolaborator dengan proses yang terkontrol. Workflow publikasi memastikan setiap perubahan direview sebelum tampil di situs utama.

✓ Workflow editor → review → publish Setiap perubahan tersimpan sebagai draft hingga disetujui, sehingga versi yang tayang selalu terkurasi.
✓ Upload gambar langsung ke media library Gunakan tombol upload pada field gambar untuk menambahkan aset baru atau pilih dari arsip yang ada.
✓ Preview responsif sebelum publikasi Gunakan tombol Preview di CMS untuk melihat tampilan konten di berbagai ukuran layar.
